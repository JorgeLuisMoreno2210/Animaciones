# Atrapa y Golpea al Conejo — Minijuego Interactivo

Videojuego web interactivo con interfaz diseñada al estilo smartphone, desarrollado utilizando únicamente tecnologías nativas de la web. El objetivo consiste en golpear al conejo en pantalla mientras un sistema de conteo dinámico registra y actualiza la puntuación en tiempo real con cada acierto.

## Características principales
* **Diseño estilo Smartphone:** Interfaz visual compacta, atractiva y responsiva creada íntegramente con **CSS puro** (sin librerías ni frameworks externos).
* **Contador de impactos en tiempo real:** Lógica en JavaScript que detecta cada clic o toque sobre el conejo y actualiza el marcador al instante.
* **Animaciones e interactividad fluida:** Transiciones visuales y respuesta inmediata diseñadas para ofrecer una experiencia arcade dinámica.

## Lenguajes y herramientas utilizadas
* **Estructura y Estilos:** HTML5 y CSS3 puro
* **Lógica e Interactividad:** JavaScript (Vanilla JS)
* **Control de versiones:** Git y GitHub Desktop
